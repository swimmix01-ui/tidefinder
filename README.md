# TideFinder 3 — 해양 수색·현장 대응지원

사고·목격 위치를 기준으로 표류 참고 경로를 계산하고, 관측자료·공개 예보·항행경보·수색 기록을 함께 확인하는 웹 앱입니다.

## 주요 기능
- KHOA 수치조류도를 매 시간 이동 중심 위치에서 재조회. 시간구간 중간 시각의 유향·유속으로 적분합니다.
- 기상청 시간별 풍향·풍속, 표류물 풍압계수와 발산각, 해안선 도달 정지, 정치망 300m 근접 확인.
- 500입자 탐색 시뮬레이션(Web Worker), 초기 위치 오차와 지속 오차·좌우발산 적용. 외곽은 확률 등고선이 아닙니다.
- 현재/도착 시각 위치 선택, 마지막 목격 위치로 기준 갱신, 수색 구역 기록, 예측 이력과 실측 위치 오차 비교.
- 사건 JSON, 지도 GeoJSON, 출처·제한 조건이 포함된 보고서 TXT, 인쇄/PDF.
- KHOA 실측 카드, ROMS/HF 독립 비교, 전국 항행경보 발행 목록, Open-Meteo 보조모델(너울·파주기·시정·돌풍·일출몰 등).
- Leaflet + OpenStreetMap 배경지도, Turf 지리 연산. 카카오 JavaScript 키 없이 지도 사용 가능.

## 실행과 검증
Node 22.3 이상(테스트는 Node 24에서도 확인).

```sh
npm ci
npm run dev
npm test
npm run build
```

`npm run dev`는 기존 배포 사이트의 Netlify 함수를 프록시합니다. 자신의 환경변수로 함수까지 실행하려면 Netlify CLI의 `netlify dev`를 사용하세요. 정적 빌드만으로 공공 API 프록시가 실행되지는 않습니다.

## Netlify 배포 설정
- Build command: `npm run build`
- Publish directory: `dist`
- Functions: `netlify/functions`, esbuild 번들러 (`netlify.toml`에 명시)
- 환경변수: `SERVICE_KEY`(공공데이터포털), `KHOA_SERVICE_KEY`(기존 KHOA 수치조류도), `TW_SERVICE_KEY`(부이/조위 최신 관측). TW 전용 키가 없으면 SERVICE_KEY로 시도합니다.
- ROMS·항행경보 등은 해당 서비스의 활용승인이 필요합니다. 키가 유효해도 승인 전에는 미수신으로 표시될 수 있습니다.
- 기존 코드에 노출됐던 인증키는 발급기관에서 교체하고 새 값을 환경변수에 등록하세요. 이 변경은 키를 교체하거나 Git 이력을 삭제하지 않습니다.
- 환경변수가 없으면 503을 반환합니다. 코드 내 인증키 대체값은 제거했습니다.
- 보조모델 API는 키 없이 비상업 공개 사용 범위에서 조회합니다. 상용·대규모 운영은 공급자 사용조건과 별도 플랜을 확인하세요.

## 현장 사용 흐름
1. 최초 사고 좌표, 한국시간 기준 일시, 예측시간(1~24h), 표류물과 초기 위치 오차를 입력합니다.
2. 예측 근거에서 구간별 자료 시각·거리·수동값·미반영 항목을 확인합니다.
3. 시간 선택에서 현재 또는 도착 시각의 위치를 확인합니다. 계산 범위를 벗어난 시각에는 외삽하지 않습니다.
4. 목격 좌표와 시각을 추가한 뒤 마지막 확인 위치로 기준을 갱신하고 다시 계산합니다. 최초 사고 위치는 별도로 보존됩니다.
5. 지도 선택 좌표를 수색구역 중심으로 사용해 수단·반경·종료시각·결과를 기록합니다.
6. 이 기기에 저장, 또는 보고서/JSON/GeoJSON을 내려받아 인계합니다. 이력은 최근 12개 예측을 보관합니다.

기기 저장은 명시적으로 버튼을 누른 경우에만 이 브라우저의 localStorage에 기록됩니다. 다른 기기와 자동 공유되지 않습니다. 서버에는 사건·목격·수색 기록을 저장하지 않습니다. 예측·관측 조회에는 좌표가 공급자/호스팅 서버에 전송되고, 지도 타일 요청에는 열람 구역이 포함됩니다. 이름·연락처 등 개인정보를 입력할 필수 항목은 없습니다. 지도와 예보는 인터넷이 필요합니다.

## 적용 한계
- 예측 신뢰도 고정 80%를 삭제했습니다. 자료 확보 상태와 실제 위치 적중률은 다릅니다.
- 조류가 미수신이면 계산을 중단합니다. 수동 입력은 전 기간 고정인 가정 시나리오로 구분합니다.
- 바람 미반영·해안선 미적용은 사용자가 별도 허용한 경우에만 진행하며 보고서에도 남깁니다.
- HF는 관측 비교용입니다. 현재 실측 한 시점을 미래 전 기간에 연장하지 않습니다.
- ROMS 원자료 응답은 확인했지만 유속 단위 공식 문서 대조 전이므로 유속을 표류 계산에 혼합하지 않습니다.
- 중심 궤적의 조류는 이동 위치별 조회, 바람은 원점 격자의 시간별 예보입니다. 입자들은 중심 궤적의 시간별 입력을 공유하며 각 입자 위치에서 해류장을 재조회하지 않습니다.
- 1시간 간격 적분으로 세밀한 연안 와류·이안류·방파제 차폐·파랑의 Stokes drift·수중 연직운동을 해석하지 않습니다. 해안 도달 시각은 구간의 거리 비례 근사입니다.
- 수중 실종은 표층 조류를 사용하는 참고 경로이며 수심별 유속·부력·침강을 반영하지 않습니다.
- 확산반경은 초기 위치 오차 + 이동거리 기반 여유 + 풍압 발산 + 시간 여유의 경험식입니다. 확률 포함률 검증 전입니다.
- 해황 참고지수는 내부 기준입니다. 풍속 또는 파고가 없으면 평가 불가이며, 수온 등 미확보 항목은 임의로 대체하지 않습니다. 공식 특보·입수 판단·생존시간 추정이 아닙니다.
- 기상특보는 최근 발표 목록입니다. 현재 발효/해제 상태를 자동 판정하지 않습니다. 항행경보는 오늘 전국 발행 최대 100건이며 주변 구역 필터나 전일 이전 유효 경보 전체가 아닙니다.
- 기존 해안선·정치망 자산은 그대로 사용합니다. 원자료의 제작 시각·위치 정확도·이용허락은 별도 확인이 필요합니다.

공개자료와 오픈소스 출처는 [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md), 변경사항과 검증은 [docs/VALIDATION.md](docs/VALIDATION.md)를 참고하세요.
