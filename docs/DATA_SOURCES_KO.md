# TideFinder 공공데이터 연결·활용신청 안내

확인일: 2026-10-17. 공식 목록·명세를 확인한 20개 자료입니다. 전체 공공데이터를 망라했다는 뜻이 아니며, “후보”는 앱에 연결된 자료가 아닙니다.

## 먼저 신청할 자료

1. **기상청 API허브**: 해양기상부이·파고부이관측(해양기상종합관측 sea_obs.php)과 해양관측 지점정보(BUOY). API허브 회원가입·키 발급 및 해당 API 활용신청. Netlify 환경변수 **KMA_AUTH_KEY**에 등록. 공공데이터포털 serviceKey와 별도입니다. <https://apihub.kma.go.kr/apiList.do?seqApi=3>
2. **해양조사원 자연과학용 수심정보 조회**: <https://www.data.go.kr/data/15142498/openapi.do>. 개발계정 자동승인, 운영계정 심의승인으로 안내됨. 승인 후 SERVICE_KEY 사용 가능 여부를 실응답으로 확인. 단위·수직기준 검증 전에는 수심 원시값만 조회하며 잠수 깊이로 표시하지 않습니다.
3. **기상특보 조회서비스**: <https://www.data.go.kr/data/15000415/openapi.do>. 현재 발표목록은 연결돼 있으나 getPwnStatus 발효현황·해역 코드 연결을 별도로 검증해야 합니다.
4. **브이월드**: 현재 CoastView의 기존 3D 연결은 유지. WMS/WFS·검색 추가 사용 시 실제 운영·프리뷰 도메인과 해당 API 권한을 확인. 3D 육상 지형은 해저 측량 자료가 아닙니다.

키는 채팅이나 GitHub에 넣지 않고 Netlify 환경변수에 등록합니다. 완료 후 서비스명·승인 상태만 알려주면 됩니다. 신청·키 등록 뒤에도 실응답 형식과 원문 수치 대조가 필요합니다.

### 신청 목적에 넣을 문안

해양 실종자 수색 및 구조대 출동 중 사고 해역의 해양·기상 관측정보, 예측정보와 지형정보를 통합 조회하는 수색지원 시스템 개발·검증. 관측소 위치·관측시각·자료 출처를 표시하고 실측과 예측을 구분하여 현장 지휘관의 상황 파악을 지원하며, 잠수 가능 여부나 구조대 투입을 자동 결정하지 않음.

## 현장 적용 전 남은 검증

- 해양기상 관측 원문과 앱 수치·방향·시간·지점 좌표 대조. API허브 인증 없이는 실자료 연결 완료라고 표시하지 않음.
- 해안 안팎·방파제·내항·외항 대표성을 직선거리만으로 판단하지 않음.
- 수심 격자의 단위·수직기준·측량연도·유효범위를 공식 활용가이드와 대조. 150m 격자로 수중 장애물 판별 불가.
- HF는 표층이며 수심별 유동 자료가 아님. 수중 조류를 임의 추정하지 않음.
- 정밀 해저지형·저질·침선·정치망·수심별 유속은 공개 범위·권한·원본 갱신일을 추가 확인해야 함. 실시간 AIS·VTS를 공개 항만 입출항 자료로 대체하지 않음.
- 인공어초 통계집 4유형 자료는 가공·재배포 없이 참고 링크로 유지.

## 수심이 표시되는 공식 바다지도 연결 (2026-10-18 확인)

- 공식 서비스: [국립해양조사원 개방해](https://www.khoa.go.kr/oceanmap/main.do). 메뉴 **오픈 API 소개 → 오픈API 신청**.
- 요청 항목: **개방해 배경지도 API**, 포항·영일만·구룡포 연안의 **수심 숫자·등심선 표시** 포함 여부와 해당 레이어 이용권한 확인. 해도객체정보 API나 150m 자연과학용 수심 API는 배경지도 API를 대신하지 않음.
- [공식 신청 안내](https://www.khoa.go.kr/oceanmap/apiguide/html/chapter02.html): 이용 신청 후 운영자 승인 및 레이어별 이용권한 필요. 가이드 화면이 오래된 경우 현재 신청 화면과 제공기관 안내 우선.
- [공식 웹 연동 예제](https://www.khoa.go.kr/oceanmap/apiguide/html/chapter05.html): 배경지도 서비스키 및 EPSG:5179 좌표계 사용. 현재 앱의 EPSG:3857 지도에 주소만 바꿔 끼우지 않음. 승인 후 실제 타일 규격·좌표계·HTTPS·제공 범위·최대 축척을 대조한 뒤 통합.
- 신청 목적: “해양경찰 구조대 출동 중 사고 해역의 수심·등심선·해안지형과 관측정보를 함께 조회하는 수색지원 웹앱. 포항·영일만·구룡포 연안을 우선 검증. 배경지도 API와 수심 표출 레이어의 외부 웹앱 이용 및 도메인 등록 절차 안내 요청.”
- 사용 도메인: `magical-ganache-c5c79f.netlify.app`, `deploy-preview-1--magical-ganache-c5c79f.netlify.app`.
- 현재 구현: 화면·기록·보고서의 도분초 표기 통일 및 공식 바다지도 새 창 링크. **앱 내부 해도 배경·수심 레이어는 미연결**. 승인·실응답 검증 전 일반지도나 미검증 격자에 해도·수심이라는 이름을 붙이지 않음.
- 개방해 서비스 자체에 “항해용으로 사용할 수 없습니다”라는 고지가 있음. 해도 수심의 수직기준·갱신일을 확인하고 현장 수심계 값과 구분.

인증키는 GitHub나 채팅에 공개하지 말고, 발급되면 승인된 서비스명·레이어명과 비밀값을 가린 명세만 전달합니다. 연동 방식에 맞는 안전한 등록 경로를 확인한 후 키를 설정합니다.
